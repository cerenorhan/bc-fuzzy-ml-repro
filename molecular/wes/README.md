# Whole-exome sequencing analyses

This directory contains reproducibility materials for the WES components of the study.

The WES analyses include:

- local non-cancer germline WES
- local breast-cancer tumour-only WES
- PRJNA913947 public paired tumour-normal WES

Local patient-level sequencing data and large intermediate files are not included in the repository.

Public sequencing data can be retrieved from the original repositories using the accession metadata provided within the relevant dataset directories.

Detailed workflow documentation is provided in:

`../README.md`
